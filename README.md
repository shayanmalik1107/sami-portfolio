# Cutframe Portfolio

Complete HTML, CSS and JavaScript source, including the latest horizontal process sections.

## Open locally
Open index.html in a browser. No installation or build is needed.
Optionally run: python3 -m http.server 8000
Then open http://localhost:8000.

## Customize
Edit content.js to set your name, email, portrait, showreel and project details.
Add media files to an assets folder, and set paths such as assets/portrait.jpg and assets/showreel.mp4 in content.js.
Project image fields control thumbnails; video fields control the playable videos.
Use direct media file URLs, not YouTube page URLs, for video fields.

Project titles are placeholders: replace them with your real project titles.

## Files
index.html: page structure
style.css: styling, responsive layout and animations
app.js: interactions, horizontal process scrolling and sound preview
content.js: personal information and media configuration
favicon.svg: browser icon

## Hosting
Upload these files to any static host. Keep index.html at the public root.
